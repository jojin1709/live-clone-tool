Features

Everything you need

Powerful features for comprehensive security testing and website cloning.

🕷️

Deep Crawling

Crawl entire websites with configurable depth, page limits, and parallel processing. Resume interrupted crawls anytime.

💉

XSS Injection

Inject custom JavaScript payloads into cloned pages. Multiple built-in payloads and custom injection support.

🌐

Browser Automation

Puppeteer-based cloning for SPAs. Headless Chrome, device emulation, and dynamic content handling.

🛡️

WAF Detection

Identify Cloudflare, Akamai, AWS WAF, and 15+ other WAFs protecting the target website.

🔍

Tech Fingerprinting

Detect CMS, frameworks, server software, and technologies used by the target application.

📊

Security Reports

Generate beautiful HTML, PDF, JSON, Markdown reports with multiple themes and detailed analysis.

🔄

Session Management

Save and restore cookies, localStorage, sessionStorage. Export as JSON, Netscape, or cURL format.

🚀

REST API

Full REST API for programmatic access. Integrate with your tools and automation workflows.

📡

Webhook Notifications

Send alerts to Slack, Discord, or custom webhooks when changes are detected.

Security

12+ vulnerability types

Comprehensive security scanning for all major vulnerability categories.

Critical

SQL Injection

Detect SQL injection patterns including UNION-based, error-based, and blind injection.

Critical

Command Injection

Find OS command injection vulnerabilities in application inputs.

Critical

XXE (XML External Entity)

Detect XML parsing vulnerabilities that could lead to file disclosure or SSRF.

Critical

SSRF (Server-Side Request Forgery)

Identify endpoints that could be abused to make requests to internal services.

Critical

Path Traversal

Detect directory traversal vulnerabilities that could expose sensitive files.

Critical

Insecure Deserialization

Find unsafe deserialization patterns that could lead to remote code execution.

Critical

Local File Inclusion (LFI)

Detect file inclusion vulnerabilities that could expose system files.

High

XSS (Cross-Site Scripting)

Find reflected, stored, and DOM-based XSS vulnerabilities.

High

CSRF (Cross-Site Request Forgery)

Detect missing CSRF protection on state-changing operations.

High

Server-Side Includes (SSI)

Find SSI injection vulnerabilities in web applications.

High

Template Injection (SSTI)

Detect server-side template injection in various templating engines.

Medium

Open Redirect

Find open redirect vulnerabilities that could be used for phishing attacks.

Usage

Quick start

Common commands to get you started.

Clone a website
node clone.js clone https://example.com
Security scan
node clone.js security https://example.com
Deep crawl with export
node clone.js clone https://example.com -d 5 --max-pages 500 --export-html
Clone with authentication
node clone.js clone https://app.example.com --basic-auth admin:password123
Start web dashboard
node clone.js dashboard -p 9090
