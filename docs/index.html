Crawl entire websites with configurable depth, page limits, and parallel processing. Resume interrupted crawls.

Prerequisites

  • Node.js 16 or higher
  • Git (optional)
  • Puppeteer (optional - for browser automation)

Usage

Basic Cloning

# Clone a website node clone.js clone https://example.com # Clone with custom injection node clone.js clone https://example.com -j "alert('XSS')" # Clone with pre-built payload node clone.js clone https://example.js -f payloads/xss-default.js # Deep crawl node clone.js clone https://example.com -d 5 --max-pages 500

Security Scanning

# Run security scan node clone.js security https://example.com # Save report node clone.js security https://example.js --output report.html

Browser Automation (SPA)

# Clone React/Vue/Angular app node clone.js browser https://spa.example.com --wait 5000 --scroll # With device emulation node clone.js browser https://example.com --emulate "iPhone 12"

Batch Operations

# Create URL file echo "https://example.com https://test.com https://demo.com" > urls.txt # Batch clone node clone.js batch urls.txt -c 5 --delay 2000

Web Dashboard

# Start dashboard node clone.js dashboard -p 9090 # Open http://localhost:9090

Architecture

1. Pre-Reconnaissance

Analyzes target, detects WAF, identifies technologies and frameworks.

2. Crawling

Deep crawls the website with configurable depth, parallel processing, and caching.

3. Security Analysis

Scans for 12+ vulnerability types including XSS, SQLi, CSRF, XXE, SSRF, and more.

4. Injection

Injects custom JavaScript payloads into cloned pages for testing.

5. Reporting

Generates beautiful reports in HTML, PDF, JSON, or Markdown format.

6. Serving

Hosts the cloned site locally for safe testing and analysis.
